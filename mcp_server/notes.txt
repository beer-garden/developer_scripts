After Docker Compose up -d

If you want a different model then you can just run model

Open WebUI
http://localhost:3000/

To setup the MCP server open Settings -> Integrations -> Add External Tool
- Change Type to MCP Streamable HTTP
- URL = http://fastmcp-server:8000/mcp
- AUTH = NONE
